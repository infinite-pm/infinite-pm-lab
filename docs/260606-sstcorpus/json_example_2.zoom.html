Shortcuts & help

Select & inspect
Click node
highlight & inspect it — click it again to clear (the S / E start & end markers too)
Click edge
select the edge (rings both ends)
Shift+Click
add a node or edge to the highlight set — Shift+Click it again to drop it. The one you clicked last gets the solid ring and the inspector; the rest are dashed.
Double-click edge
if its other end is off-screen, jump the view there
? badge
a hidden cross-component edge — click to reveal it, double-click to jump to the node at its far end
Click empty
clear the selection (all of it)
Open / collapse a node
+ chip
the corner badge — a single click opens/collapses
Double-click
same as the chip
Ctrl/⌘+Click
same — opens the whole subtree
… +Alt
open just one level instead

A highlighted node stays highlighted after it opens; a plain click never navigates.

Move around
Drag
pan — you can start the drag anywhere, even on a node
Scroll
zoom in / out
Esc
clear the selection, then zoom out
Breadcrumb
jump back to a parent state (top bar)
◀ ▶ or [ ]
step back / forward through your recent views (highlight, open, zoom — pan/zoom restore with each step)
Toolbar (View panel)
◀ ▶
back / forward through your recent views
▤
show / hide the inspector panel
⋮
more actions: this help, copy view URL, expand all, unexpand all, download offline copy
